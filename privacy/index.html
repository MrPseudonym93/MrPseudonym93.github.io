Privacy Policy

Overview

Pathfinder is a private, non-commercial job-discovery application built for and used by one person. It runs locally on the owner's Mac and is not available to other users.

Google data Pathfinder accesses

Pathfinder requests the Gmail read-only scope. The application uses that access only to locate and read configured job-alert messages and structured Pathfinder digest emails, using their sender, subject or Gmail label. It does not use unrelated email content.

Pathfinder also requests the Gmail send scope. It uses that access only to send structured job-review requests from the owner to the owner's own Gmail address. Those requests contain vacancy information; they do not contain unrelated Gmail messages.

Pathfinder cannot delete, archive, label, modify or impersonate email.

How data is used

Relevant vacancy details are extracted to create and update the owner's local job database. Gmail message identifiers are retained locally so that a message is not imported twice. Structured review requests and resulting digest emails form a user-controlled bridge to an external ChatGPT workflow.

Storage and security

The Pathfinder database and Google OAuth credentials are stored locally on the owner's Mac. They are excluded from the application's Git repository. Pathfinder does not operate a hosted user database or advertising system.

Sharing, sale and advertising

Pathfinder does not sell Google user data, use it for advertising, or share it with data brokers. Job-vacancy information deliberately submitted through the owner's Gmail account may be processed by the owner's separately configured ChatGPT workflow to produce a structured job review.

Retention and deletion

Local records are retained until the owner deletes them. The owner can stop access at any time by revoking Pathfinder in their Google Account permissions and deleting the local OAuth token. Local application data can be removed by deleting the Pathfinder database.

Google API Services User Data Policy

Pathfinder's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Contact

Questions about this policy can be directed to the project owner through the support address displayed on Pathfinder's Google OAuth consent screen or through the project owner's GitHub profile.
